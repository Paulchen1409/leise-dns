Mit Windows starten

Leise DNS startet nach der Anmeldung unauffällig im Infobereich, ohne Fenster. Ein eingeschalteter Schutz wird fortgesetzt.

Windows-Freigabe merken

Nach einer einmaligen Bestätigung schaltet Leise DNS den Schutz ohne erneute Windows-Abfrage ein – auch nach einem Neustart. Dafür legt Windows eine Aufgabe an, die nur das geschützte Leise-DNS-Hilfsskript mit Administratorrechten startet.

Wird geprüft …

Auch verschlüsselte Seiten (https)

Fast alle Seiten nutzen https. Damit der Browser die Hinweisseite auch dort zeigt, installiert Leise DNS ein eigenes Stammzertifikat – nur für dein Windows-Konto, Windows fragt dabei nach. Der Schlüssel bleibt verschlüsselt auf diesem PC, und Zertifikate entstehen nur für gesperrte Malware- und Phishing-Domains. Ohne diese Option sind solche Seiten trotzdem gesperrt; der Browser zeigt dann nur eine Fehlermeldung.

Gut zu wissen

  • Das Schließen des Fensters lässt Leise DNS im Infobereich weiterlaufen. Über das Tray-Symbol erreichst du Schalter und Dashboard.
  • Apps mit eigenem verschlüsseltem DNS können den lokalen Filter umgehen. Werbung von derselben Domain wie der Inhalt lässt sich per DNS nicht getrennt sperren.
  • Neue Netzwerkadapter, etwa nach dem Verbinden eines VPN, werden durch Aus- und Einschalten übernommen. Leise DNS ändert keine Routereinstellungen.
